# Hisob

Личный учёт денег для iOS: источники дохода (места работы), личные траты
по месяцам и остаток, который переносится из месяца в месяц.

Перенос финансового модуля веб-версии (Next.js + Postgres) на нативный Swift.

## Структура

```
hisob/
├── HisobCore/          SwiftPM-пакет: домен и расчёты (без SwiftUI)
│   ├── Sources/HisobCore/
│   │   ├── Models/         YearMonth, Money, Expense, IncomeSource, Ledger
│   │   ├── Services/       LedgerCalculator, Analytics, ExpenseQuery
│   │   └── Repositories/   LedgerRepository (протокол) + in-memory
│   └── Tests/              57 тестов
├── Hisob/              приложение SwiftUI (App, DesignSystem, Features)
└── docs/
    ├── model.md        решения по доменной модели и чем она отличается от вебa
    └── migration.md    выгрузка прод-данных из Postgres и правила переноса
```

Домен вынесен в отдельный пакет намеренно: граница слоёв держится физически,
а тесты гоняются из терминала без симулятора.

## Запуск тестов

```bash
cd HisobCore && swift test
```

## Статус

Готово:
- доменная модель и все расчёты (доход, потрачено, перенос, остаток)
- аналитика: разбивка по категориям, суммы по месяцам
- фильтр и поиск по тратам с ранжированием
- протокол хранилища с точечным CRUD + реализация в памяти
- 57 тестов, включая сшивание цепочки переноса при смене работы

Дальше:

- импорт прод-данных (см. `docs/migration.md`)
