# Hisob

Личный учёт денег для iOS: источники дохода (места работы), личные траты
по месяцам и остаток, который переносится из месяца в месяц.

Перенос финансового модуля веб-версии (Next.js + Postgres) на нативный Swift.

## Структура

```
hisob/
├── HisobCore/          SwiftPM-пакет: домен и расчёты (без SwiftUI)
│   ├── Sources/HisobCore/
│   │   ├── Models/         YearMonth, Money, Expense, IncomeSource, Ledger
│   │   ├── Services/       LedgerCalculator, Analytics, ExpenseQuery
│   │   └── Repositories/   LedgerRepository (протокол) + in-memory
│   └── Tests/              57 тестов
├── Hisob/              приложение SwiftUI (App, DesignSystem, Features)
├── api/                тонкий REST-слой поверх Neon (Hono + Prisma)
└── docs/
    ├── model.md        решения по доменной модели и чем она отличается от вебa
    └── migration.md    выгрузка прод-данных из Postgres и правила переноса
```

Домен вынесен в отдельный пакет намеренно: граница слоёв держится физически,
а тесты гоняются из терминала без симулятора.

## Запуск тестов

```bash
cd HisobCore && swift test
```

## Запуск приложения

```bash
cp Signing.xcconfig.example Signing.xcconfig
```

Впишите в него свой Team ID (Xcode → Settings → Accounts → ваш Apple ID → Team).
Файл не хранится в git: проект генерируется из `project.yml`, и команда,
выбранная в интерфейсе Xcode, слетала бы при каждой перегенерации.

```bash
xcodegen generate && open Hisob.xcodeproj
```

Проект в git не хранится — генерируется из `project.yml`.

### Установка на iPhone

1. На телефоне включить режим разработчика: Настройки → Конфиденциальность
   и безопасность → Режим разработчика.
2. Подключить кабелем, выбрать устройство в списке целей Xcode, нажать Run.
3. При первом запуске телефон не доверяет сертификату: Настройки → Основные →
   VPN и управление устройством → выбрать разработчика → Доверять.

С бесплатным Apple ID приложение работает **7 дней**, после чего его нужно
переустановить из Xcode. Программа Apple Developer ($99/год) продлевает срок
до года. Ничего из того, что использует приложение, платного аккаунта не
требует: Keychain работает и на бесплатном.

Без настроенного подключения приложение работает на демонстрационных данных.
Адрес API и токен задаются в Настройки → Подключение; токен хранится в Keychain.
