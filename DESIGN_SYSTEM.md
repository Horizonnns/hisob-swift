# Дизайн-система Hisob (iOS)

Источник правды по визуалу. Значения — в `Hisob/DesignSystem/`, не хардкод по вью.
Палитра унаследована от веб-версии, адаптирована под нативный тёмный/светлый режим.

## Цвета (Color assets / DesignSystem)
- Brand / accent: `#5B4FFF` — активный таб, основная кнопка, акцент графиков
- Success (доход): `#10B981`
- Danger (расход, перерасход): `#EF4444`
- Info (остаток): `#3B82F6`
- Highlight (перенос): `#6366F1`
- Текст: `.primary` / `.secondary` системные — не переопределять
- Фон: чистый чёрный в тёмной теме — на OLED гаснет полностью, карточки
  читаются как приподнятые слои. Поверхности: `#131315` (карточка),
  `#1F1F23` (поля, чипы), разделитель `#2A2A2E`

Палитра графиков (по кругу): brand, info, success, `#F59E0B`, danger, `#EC4899`

## Типографика (Font styles, поддержка Dynamic Type)
- H1 — `.largeTitle.bold()` — заголовок экрана
- H2 — `.title2.weight(.semibold)` — заголовок секции
- Amount — `.title.weight(.bold).monospacedDigit()` — крупная сумма в плашке
- Body — `.body`
- Caption — `.caption` + `.secondary` — подписи, даты, метки категорий

Никаких кастомных шрифтов: системный San Francisco уважает Dynamic Type
и не требует бандлинга.

## Отступы
- Шкала: 4, 8, 12, 16, 24, 32 — только из шкалы (`DS.Spacing`)
- Радиус карточек: 16; плашек-статистики: 12
- Поля экрана: 16

## Компоненты (проверять СНАЧАЛА здесь — не дублировать)
- `DSButton` — варианты: primary, secondary, ghost, danger
- `DSCard` — карточка на `.ultraThinMaterial`
- `StatTile` — плашка «подпись + сумма + иконка» (Доход / Потрачено / Перенос / Остаток)
- `MonthSwitcher` — переключатель месяца со стрелками
- `CategoryChip` — фильтр-чип категории со счётчиком
- `AmountText` — сумма с валютой и моноширинными цифрами
- `DSTextField`, `AmountField` — ввод текста и суммы

## Действия над строкой

Три способа, все системные:

- **свайп влево** — удалить;
- **свайп вправо** — изменить;
- **нажатие с удержанием** — меню с обоими действиями.

У контекстного меню задаётся своё превью (`contextMenu(menuItems:preview:)`):
без него система приподнимает строку как есть, без подложки, и на чёрном
фоне она теряется. С превью строка всплывает отдельной карточкой, а меню
раскрывается рядом — как в Telegram.

## Состояния (обязательны для экрана с данными)
- loading — скелетоны плашек и строк списка, без спиннера на весь экран
- empty — SF Symbol + текст + основное действие («Добавить расход»)
- error — текст ошибки + кнопка «Повторить»

## Иконки
- SF Symbols, размер по умолчанию 17 (в плашках статистики — 20)
- Доход `arrow.up.right`, расход `arrow.down.right`, перенос `arrow.turn.down.right`,
  остаток `wallet.bifold`, источник дохода `briefcase`
